Do firmware à web: ferramentas nascidas de problemas reais de quem programa embarcados e projeta instalações elétricas.

main.cpp + monitor serial, 115200 baud
#include <xLogger.h>

XLogger logger(Serial);

void setup() {
  Serial.begin(115200);
  logger.info("boot ok");
}

void loop() {
  int adc = analogRead(A0);
  logger.debug("adc=", adc,
               " volts=", adc * 5.0 / 1023);
  delay(1000);
}
[I] boot ok
[D] adc=512 volts=2.50

xLogger

Biblioteca C++ · Arduino, ESP32, ESP8266 · MIT

Logs de depuração que funcionam como Serial.print(), mas podem ser desligados sem comentar linhas e removidos por inteiro do firmware final.

Skills técnicas

  • C++11 com templates em biblioteca header-only, sem dependências
  • Registro sem String, evitando alocação no heap e fragmentação
  • Remoção em tempo de compilação por nível de log
  • CI que inspeciona firmware real de Uno e ESP32

Skills pessoais

  • Empatia com quem usa: a API aproveita o que a pessoa já sabe de Serial.print()
  • Documentação em inglês e português, com guia passo a passo
  • Cuidado com a comunidade open source: versões, changelog e guia de contribuição
